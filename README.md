# Correspondence & Outgoing System

نظام إدارة المراسلات والصادرات مصمم لتنظيم جميع العمليات المتعلقة بالصادر والوارد للمؤسسات.  
يوفر هذا النظام لوحة قيادة متكاملة، إدارة المستخدمين، متابعة المحذوفات، إعدادات النظام، وإمكانيات النسخ الاحتياطي والصيانة.

---

## نظرة عامة على النظام

النظام يحتوي على الأقسام الرئيسية التالية:

### لوحة القيادة
- Dashboard: عرض ملخص شامل عن نشاطات النظام.

### الصادر (Outgoing)
- الصادر
- الصادر العام

### الوارد (Incoming)
- استقبال المراسلات الواردة.

### المحذوفات (Deleted)
- محذوفات الصادر
- محذوفات الوارد

### المستخدمين (Users)
- إدارة المستخدمين، إضافة وتعديل الصلاحيات.

### الإعدادات (Settings)
- الشركات (Company)
- نوع المعاملة (Transaction Type)
- الجهة (Dialect)
- الأهمية (Importance)
- السرية (Confidentiality)
- الإشعارات (Notifications)
- وضع الصيانة (Repair Mode)
- النسخ الاحتياطي (Backup)
- وقت إضافي (Overtime)

### تسجيل الخروج
- Logout: لإنهاء الجلسة بأمان.

## مميزات النظام

- متابعة الصادر والوارد بشكل مرتب.
- إدارة المستخدمين والصلاحيات.
- مراقبة المحذوفات لضمان عدم فقدان البيانات.
- إعدادات مرنة تشمل الشركات، نوع المعاملات، الجهات، الأهمية، السرية والإشعارات.
- إمكانية النسخ الاحتياطي واستعادة البيانات.
- وضع الصيانة وصلاحيات الوقت الإضافي.
- واجهة سهلة الاستخدام ومرنة.
